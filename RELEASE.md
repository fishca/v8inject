Этап стабильности + нативный пункт меню (WIP). Оверлей-реплика в ряду
меню Конфигуратора больше не вешает 1С при открытии меню, пункты не
съезжают, хуки стресс-протестированы. Нативный пункт — каркас готов,
RE-задача для служебного реестра в плане (docs/plan_mainmenu_re.md).

## Что нового

- **Оверлей больше не вешает 1С при открытии меню.** Клик по реплике
  «Окна»/«Справка» открывает родное меню в модальном цикле на UI-потоке —
  UIA-перепросы оверлея в этот момент вешали конфигуратор. Пауза маршала
  на время модального цикла + скрытие реплики устраняют это.
- **Пункты меню не съезжают.** Выпадающая панель 1С привязывается к
  родной кнопке, которая под оверлеем на ширину пункта «GitBar» левее
  видимой реплики. Хук обёртки config.dll сдвигает панель вправо на эту
  ширину — меню встаёт под видимой репликой.
- **Оверлей следует за окном при перетаскивании.** Раньше он оставался
  на старых экранных координатах и отделялся от ряда меню.
- **Пункты не пропадают.** Первый вариант скрывал оверлей целиком на
  10 с; теперь пауза только отключает UIA-вызовы.
- **Стресс-тест хуков в CI.** Четыре потока × циклы установки/снятия
  хука на живой цели; убийство цели посреди сессии; трасса минимум
  с двух потоков. ctest теперь 4 теста на каждой разрядности.
- **Парсер импортов x64** читает 8-байтовые тунки (IMAGE_THUNK_DATA64) —
  раньше один мусорный пункт на DLL.
- **Инъекция в свежий процесс** стабильна: ретрай поиска kernel32 в цели
  (launch-инъекция до заполнения модульного списка).
- **Маршал построения** нативного меню через общий cmd-канал (режим 3 +
  SRWLOCK) — fallback через замену WndProc и переустановку при
  пересоздании окон 1С унаследованы от cmd-цепочки.

## Нативный пункт меню (WIP)

Каркас нативного пункта «GitBar» в главном меню Конфигуратора готов
(хуки обёрток getService, общий маршал, цепочка построения, SEH, ключ
`nativemenu=0`). Блокирует: служебный реестр сервисов Конфигуратора
использует внутренние ключи вместо классических IID. План RE —
`docs/plan_mainmenu_re.md`. Оверлей-реплика остаётся рабочим UI до
завершения RE; ключ `menuoverlay=0` отключает её.

## Исправлено

- Снятие хука только при успехе восстановления байтов;
- Пункты реплики не прыгают (сдвиг панели привязан к конкретной кнопке);
- Слоты GetService перебираются 8–24 с поведенческой проверкой;
- current_process ищется по всем core-модулям (core_as.dll в т.ч.);
- Профильные API KERNELBASE убраны из потока меню (GetPrivateProfile
  StringW ронял поток на канонизации пути);
- Рабочий поток под SEH; пошаговый журнал каждого маршал-вызова.

## Проверено

- Сборка x86/x64 Release без предупреждений; x86 — с /WX.
- ctest — 4/4 на обеих разрядностях (cli_help, unit 48 тестов /
  618 проверок, hook_smoke, hook_stress);
- hook_stress — 10/10 прогонов x64, 3/3 x86;
- Живой прогон на 8.3.27.2342: инъекция стабильна, оверлей не вешает
  1С, пункты не съезжают при открытии меню и перетаскивании окна.
