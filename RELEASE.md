Иконки GitBar снова пересмотрены: теперь это глифы открытого набора
**Phosphor Icons** (Fill, MIT), перекрашенные в палитру и «пластиковую»
стилистику Конфигуратора. Набор собран по назначению пунктов меню, а в
репозитории не осталось ни одной картинки из ресурсов 1С.

## Что нового

- **Открытый набор вместо самодельных глифов.** После отказа от картинок из
  ресурсов 1С (v0.6.0) иконки были нарисованы вручную — работало, но выглядело
  простовато. Теперь глифы берутся из открытого набора Phosphor Icons
  (`@phosphor-icons/core` 2.1.1, лицензия MIT, https://phosphoricons.com):
  профессиональные пропорции и единый стиль, лицензия разрешает
  распространение и переработку.
- **Перекраска в палитру Конфигуратора.** `tools/render_icons.cjs` берёт
  SVG-исходники из `src/payload/icons/phosphor/`, заливает их вертикальным
  градиентом «светлый → тёмный» (зелёный — файлы/репозиторий, синий — git,
  бирюзовый — синхронизация, золотой — списки/архив, коричневый — история,
  серый — настройки) и рендерит PNG 16×16 с прозрачным фоном. `tools/gen_icons.py`
  по-прежнему собирает `icons.h` (premultiplied BGRA для панели) и
  `icons_png.h` (PNG для `file:///`-URL нативного меню) — панель и подменю
  используют одни и те же файлы.
- **Набор по назначению пунктов.** «Выгрузить исходники» — файл со стрелкой
  вниз, «Выгрузить расширение» — пазл, «Создать репозиторий» — папка с плюсом,
  «Клонировать» — копия, «Коммит» — git-узел, «Пуш»/«Забрать» — круговые
  стрелки, «Получить» — две круговые стрелки, «Ветки» — git-branch,
  «Отложенные» — архивный ящик, «Теги» — бирка, «Рабочая копия» — чек-лист,
  «История» — часы, «Настройки» — шестерёнка, сам «GitBar» — git-fork.
- **Лицензионная чистота.** SVG-исходники Phosphor (MIT) лежат в
  `src/payload/icons/phosphor/` вместе с `LICENSE.txt` и `ATTRIBUTION.md`;
  назначение и цвет каждой роли — в `src/payload/icons/SOURCE.json`.
  Уведомление об авторских правах продублировано в README и в этих заметках.

## Изменено

- `tools/draw_icons.py` удалён — самодельные глифы больше не нужны;
  вместо него `tools/render_icons.cjs` (node + sharp, dev-only установка
  `npm install --no-save sharp`; сборка и CI скрипт не запускают — PNG
  закоммичены).
- Документация (`README.md`, `docs/GITBAR.md`, `docs/ARCHITECTURE.md`,
  `docs/plan_mainmenu_re.md`) обновлена под новый источник иконок.

## Проверено

- Release-сборки x64 и x86 собираются без предупреждений; на каждой
  архитектуре пройдены 4/4 CTest: `cli_help`, `unit`, `hook_smoke`,
  `hook_stress`.
- Live 8.3.27.2342 x64: панель `V8iGitBar` и нативное подменю с новыми
  глифами; в журнале payload —
  `иконки заданы в описаниях (15/15, загружено платформой 15/15, …)`,
  то есть платформа собрала `IImage` по всем нашим `file:///`-URL.

## Установка

`v8inject-v0.7.0-x64.zip` / `v8inject-v0.7.0-x86.zip` — `v8inject.exe`,
`v8inject-gui.exe`, `v8inject-agent.exe`, `v8i_payload.dll`. Распакуйте архив
той же разрядности, что ваша платформа 1С, и запускайте `v8inject.exe`,
`v8inject-gui.exe` или `v8inject-agent.exe` из каталога с `v8i_payload.dll`.
Нативный пункт меню включён по умолчанию; ключ `[git] nativemenu=0` в
`%APPDATA%\v8inject\gitbar.ini` возвращает оверлей-реплику.
